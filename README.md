# Mariam Tariq Portfolio

This repository contains a modern personal portfolio website for Mariam Tariq.

## Local preview

Open `index.html` in a browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

Because this repository is named `mariamtariq-growth.github.io`, GitHub Pages can serve the site directly from the `main` branch once Pages is enabled in the repository settings.
